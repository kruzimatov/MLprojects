# ML Projects — Classic Machine Learning from Scratch

Linear Regression implemented three ways: closed-form solution, gradient descent from scratch, and full sklearn workflow — then applied to a real business dataset.

## Folders

### [linear-regression-fundamentals/](linear-regression-fundamentals/README.md)
Three exercises, each teaching one core technique in isolation.
- **01-normal-equation** — closed-form solution from scratch (Credit dataset)
- **02-gradient-descent** — iterative optimization from scratch (Concrete dataset)
- **03-sklearn-workflow** — leakage-safe end-to-end pipeline (Palmer Penguins)

### [linear-regression-practices/](linear-regression-practices/README.md)
Applying the fundamentals to a full, messy, real-world dataset.
- **04-walmart-sales** — weekly sales prediction with time-based splitting

Each project folder has an `EXPLANATION.md` — a full walkthrough of every code cell: what each pandas/NumPy/sklearn function does, why that step exists, and the theory behind it.

## Tech Stack
Python, NumPy, pandas, matplotlib, seaborn, scikit-learn
